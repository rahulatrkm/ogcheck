# OGCheck

**Is your link preview broken? Find out in one request.**

> 🟢 **Live:** https://ogcheck-app.azurewebsites.net (deployed on Azure App Service free tier)

You add an `og:image`, ship it, and forget. Weeks later a post gets half the
clicks — because the image 404s and nothing told you. OGCheck catches it.

It validates a page's **Open Graph / Twitter Card** tags and — the part most
tools skip — **confirms the `og:image` actually returns HTTP 200**. Use it as a
one-line CLI, a CI check that fails your build, or a JSON API.

Zero dependencies (pure Python standard library). Free to run, free to host.

---

## Use it

```bash
# CLI (exits non-zero if the preview is broken — perfect for CI)
python -m ogcheck https://your-site.com/blog/post

# JSON API
python -m ogcheck.api            # serves on :8000
curl "localhost:8000/check?url=https://example.com"
```

Example output:

```
OGCheck — https://example.com
  score : 7/100   FAIL
  [ERROR] Missing og:title — social previews need it.
  [ERROR] Missing og:image — social previews need it.
```

## Why it's different

Social-image *generators* are a crowded space. Social-image **validation +
monitoring** is the gap: a stateless "ESLint for your link preview" that tells
you *before* traffic drops. That's what this is.

## Deploy free

It's a single stdlib process — host it anywhere with a free tier:

- **Render / Fly.io free container** — `docker build` from the included
  [Dockerfile](Dockerfile), or point Render at this repo ([render.yaml](render.yaml)).
- The landing page is served by the same process at `/`.

```bash
docker build -t ogcheck . && docker run -p 8000:8000 ogcheck
```

## Distribution (free)

- **GitHub Action** ([action.yml](action.yml)) — drop it in any repo to fail CI
  on a broken preview. Marketplace = free reach.
- **SEO landing pages** — generated by `python -m ogcheck.seo` into `web/`, served
  at clean URLs. They target the terms people search *when their preview is
  already broken*: "og:image not showing", "check open graph tags", "social
  preview validator". Each has genuinely-helpful content + the live checker.
- **Where to post:** r/webdev, r/juniordev, r/SEO, dev.to, Indie Hackers.
