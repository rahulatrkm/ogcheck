Your link preview is probably broken.

You add an og:image, ship it, and forget. Weeks later a post gets half the clicks — because the image 404s and nothing told you. OGCheck catches it in one request.


    


    
How it works

    
    
      
  • Parses your Open Graph, Twitter Card, and SEO tags.
    • 
      
  • Verifies your og:image actually returns HTTP 200 — the #1 silently-broken thing.
    • 
      
  • Returns a score + the exact fixes. Use it as an API or a CI check that fails your build.
    • 
    


    
GET /check?url=https://example.com  JSON report. That's the whole API.


    
The full site-health suite
